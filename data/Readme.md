These PDFs are inputs to the Chroma document index, not training examples or evaluation results. The corpus mixes official Python documentation with third-party teaching material. It does not constitute a complete or uniformly current Python reference.

Third-party documents retain their original terms; this repository does not grant a new license to them. The indexer reads PDFs from this directory, and prompts identify retrieved passages as references with source filenames and page indices. Retrieval does not establish that a passage is relevant or that a generated correction is correct.
